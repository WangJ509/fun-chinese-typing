# Fun Chinese Typing（注音打字稿紙）

一頁式的中文打字練習：在稿紙上對著詩詞、散文直接打字，按 Enter 送出選字就立刻批改。

- 每格上面是原文，下面直接打字；組字中的字以底線顯示。
- 每次送出選字就會批改，錯字畫紅圈；整句打完再按一次 Enter 交卷，交卷後按 Backspace 可以回去改。
- 成績依題組統計：整句全對的比例、逐字正確率、每分鐘字數（送出的國字與標點，從第一個按鍵算到交卷）。
- 不需要伺服器或帳號，作答紀錄只存在瀏覽器的 localStorage。

## 題目

題目在 `texts.tsv`，分成古典詩詞、現代詩、古文、現代散文，只收已進入公有領域的作品。詩詞用「/」標出原本的分行，網頁照著換行，行太長時只在標點後折行；散文自動折行，標點不會出現在行首。冷僻字或特殊讀音在字後面加 `{注音}`（例如 `蓑{ㄙㄨㄛ}`），網頁會把注音直排標在字的右邊，上方的「冷僻字注音」可以關掉。修改後執行下面的指令，把題目寫進 `index.html`：

```bash
python3 make_data.py
```

## 在本機執行

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

打開 <http://127.0.0.1:8765/>。
